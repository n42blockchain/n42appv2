Face ID 只能恢复有效会话。退出账号已使 Matrix 令牌失效时，需要正常重新认证；本轮不会保留已退出令牌或存储账号密码。用户尚未确认失败发生在退出账号、重新打开 App，还是系统未弹验证，因此不能声称已经复现并修复该设备上的全部 Face ID 故障。

双端需使用专门测试账号复核：有效会话恢复、退出后回到正常登录、系统权限关闭/恢复、Face ID 或指纹启停、通讯录进入资料页、更新备注及删除好友后的按钮变化。

## 行为

- 会话“未读提及与回复”从服务端分页到精确已读标记，按原消息 ID 判断直接回复，不受当前页面加载条数限制。不完整的扫描明确显示状态。结果是可刷新的快照，不冒充持续后台索引。
- 群聊追赶面板提供历史补发入口。管理员确认策略后启用；时间窗口/条数可配置。接收人必须在源群内，并拥有无额外受邀/已加入成员的现有加密私聊。确认前展示 canonical 正文、数量、接收人和时间范围；只重新加密明确选中的普通文本，不导出源密钥。群内记录请求/完成审计。
- 发送步骤的持久状态先于 HTTP 发布；结果未知时只对账，不自动重发。恢复列表不需要重读原正文。权限、内容、群策略、成员或账号变化阻止继续；已确认的网络结果与尚未完成的审计分开记录。
- iOS 27+ 接入本机 SDK 已核实的 `SuggestedActionsView`，支持系统提供的日历、提醒和地图建议。宿主添加 `com.apple.developer.suggested-actions` entitlement；确认前仅探测能力，确认后仅交给系统一条非阅后即焚文本、事件 ID、时间和本人发送标记。不给系统历史上下文、地址簿或钱包操作接口。其他平台/旧系统继续使用现有显式时间日历规则。

## 回归中修复的问题

1. 未就绪的 SDK 调用订阅初始化后，后续无法订阅。现在无客户端时不标记已订阅。
2. 同一地址的 Ethereum/Polygon 模型被错误去重。现在 EVM 去重身份包含实际网络 ID，保留两个网络的账户权限。
3. 其他会话到期误触发当前会话断开。现在只对匹配当前 topic 的到期事件请求断开。

新增回归在旧生产实现上出现 4 个断言失败，对应上述 3 个根因；[开发阶段旧实现日志](regression-before.log.gz)还包含当时测试替身定时器清理的失败，不能当成额外生产缺陷。最终全量测试全部通过。

# Apple UI and appearance validation

Date: 2026-10-12. App source: `8a3449c3bb5cf20266c2844dc2f8f8935178d607`; Chat source: `d7ad37ada3bc0960517fbd83d469561be82d3b68`.

## Changes

- Apple system colors are the default. All seven prior style presets and all eight prior accent swatches remain selectable; Apple adds an eighth style and ninth swatch. Saved custom colors remain intact. Reset selects Apple system blue, which resolves separately in light and dark mode.
- SF Text/Display aliases on Apple platforms, 17pt body, semantic type ramp, size-specific tracking and line metrics. Other platforms retain system font fallback. Type and spacing use logical points rather than screen-width multiplication. Ordinary UI tracking overrides were removed; OTP grouping and splash brand lettering remain deliberate exceptions.
- Shared buttons, inputs, navigation, dialogs, sheets and rows use consistent styles and at least 44pt touch targets. Adaptive switches/dialogs use native platform presentation. Layouts grow or scroll at large text sizes. Loading buttons block repeat submissions.
- Wallet filters stack on narrow/large-text scenes; sorting/filter actions can scroll horizontally. Asset and feature cards follow the selected accent. Feature cards grow with system text and preserve semantic type size. Empty states can scroll on short panes. Chain selection and mover rows no longer overflow after the type-size change. Offline gas cards show Unavailable after requests settle.
- Chat preserves host typography/colors/component themes, removes its 1.18 scaling cap, and composes font preference with the OS scaler without losing nonlinear scaling.

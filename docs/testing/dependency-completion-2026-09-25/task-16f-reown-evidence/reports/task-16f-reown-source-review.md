The exact locked vendored sources used by candidate1 read `OPENSSL_CONFIG_DIR` in `candidate1/cargo-home/registry/src/.../openssl-sys-0.9.116/build/find_vendored.rs:7` and `OPENSSL_SRC_PERL` in `.../openssl-src-300.5.5+3.5.5/src/lib.rs:157`; `PERL` is a fallback there. Clear the relevant inherited OpenSSL/native-helper environment or explicitly pin intended values, and test that rejection. The retained candidate hashes still identify the actual candidate bytes; this is a repeatability guard gap.

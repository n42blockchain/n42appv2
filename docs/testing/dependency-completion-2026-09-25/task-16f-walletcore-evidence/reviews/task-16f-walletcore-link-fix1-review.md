## Remaining environment finding

1. **Validate and parse the same bytes.** `scripts/walletcore_android_link.py:56-64` calls `digest(path)` and then separately `path.read_text()`. A concurrent replacement between those reads can make the digest match the pinned 20-key file while the returned mapping contains a different `PATH` or compiler flag. The returned map is passed directly to CMake. The new hash/shape check and its placement before the CMake source mutation correctly reject stable add/change/remove tampering, but do not bind the bytes parsed to the bytes checked. Read once with `raw = path.read_bytes()`, compare `sha256_bytes(raw)` to the expected digest, then parse `raw`; add a focused replacement-between-reads control if useful. This is a bounded repair to the new function, not a request to rewrite other manifest readers. The preserved RED log first fails because the function is absent; normal and `python3 -O` logs each show **3/3 passed** after the fix, including stable add/change/remove rejection.

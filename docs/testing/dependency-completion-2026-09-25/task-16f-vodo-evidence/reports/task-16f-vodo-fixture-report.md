## Runtime selection and source path

The isolated harness has a fixture-only `N42_SMOKE_VODO_RELEASE_JNILIBS` source directory. It packages a renamed **byte-identical** arm64 member from the reviewed release AAR, `libvodozemac_release_probe.so`, alongside the separately built debug library. `--dart-define=N42_VODO_RELEASE_PROBE=true` selects `vodozemac.init(stem: 'vodozemac_release_probe')` before any Vodo API call. `vodozemac-0.8.0/lib/src/api.dart` passes that stem to `loadExternalLibrary`, then to the generated `RustLib.init(externalLibrary: ...)` singleton. Account, signature, group-session and pickle calls use that singleton's generated API. The test also opens the selected `.so`, resolves the FRB account-key entry point, and records its actual executable `/proc/self/maps` region. This establishes an actual release member method dispatch attempt and completed crypto calls; the test does not rely only on mapping a library unrelated to the API.

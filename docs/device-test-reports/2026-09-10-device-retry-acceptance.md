## 环境问题与脚本修正

- Android 安装限制已经解除，本轮覆盖安装成功。
- iOS 后台执行环境的 `codesign` 仍返回 `errSecInternalComponent`；相同 identity、相同临时文件在 Mac 图形 Terminal 会话中签名成功，随后该会话中的 Flutter 构建、安装和集成测试也通过。根据这组对照结果，采用 GUI Terminal 执行签名构建，无需继续修改证书或钥匙链权限。[Apple 的执行上下文排查说明](https://developer.apple.com/forums/thread/712005)提供了相同的诊断方法。
- Android 启动测试第一次受到并行 UIAutomator accessibility 查询影响，结束时出现未释放 SemanticsHandle 断言；停止并行 UI 层级查询后，重复同一启动测试通过。测试运行期间不再执行 accessibility dump。
- 导航脚本原来使用 `tester.testTextInput.hide()`，真机未注册模拟键盘，触发 `isRegistered` 断言。改为平台 `TextInput.hide` 通道。
- 导航脚本原来等待不存在的 `wallet_page` 标识；改为应用实际声明的 `home_content_wallet`。同时增加目标确实打开的检查与分步骤日志。
- 浏览器使用自定义工具栏关闭按钮，侧栏使用独立关闭图标；脚本分别点击实际退出控件，不再对这些界面调用仅识别标准返回按钮的 `pageBack()`。
- 真机返回动画结束前，原脚本可能找到首页控件但点击仍被退出动画拦截。`_tapKey` 现在等待 `hitTestable()`，解决两个平台二维码菜单的偶发漏点，不通过忽略点击警告或无限重试掩盖问题。
- 本次导航使用 `N42_E2E_INCLUDE_CHAT=false`；测试名称和输出明确排除需要登录的 Chat。默认模式仍保留完整 Chat 检查，未将缺少凭据的功能计为通过。

## 未完成验收及服务限制

真机日志出现行情代理及部分余额请求的 HTTP 401、余额回退缓存等问题；行情列表可以通过回退数据继续显示，**不能据页面可打开推断实时行情或所有链余额正确**。后端认证、实时数据新鲜度仍需单独修复与验证。

此前 Sui 公共 JSON-RPC 废弃、Dart 与原生签名协议不一致的问题仍待修复。此前 Mac 官方 SDK 的 Sui Devnet 交易与本次真机 Solana 签名是不同检查，不能合并声称 N42 已完成链上 UI 闭环。

本轮没有导入或覆盖已有钱包、发起主网交易、读取助记词或恢复设备备份。首次测试遗漏 `--no-uninstall` 导致的 iOS 应用移除及数据恢复未核实问题，仍以首次记录为准；本轮覆盖安装成功不代表此前数据已恢复。

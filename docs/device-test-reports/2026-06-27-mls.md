## Notes

- The current mobile ABI supports one key package per `addMembers` call and one
  numeric leaf index per `removeMembers` call. The MethodChannel returns
  `INVALID_ARGS` for multi-item calls until the C ABI grows packed multi-member
  functions.
- `createGroup` and `processWelcome` return empty Dart `state` bytes because the
  real MLS group state is owned by the Rust engine. Existing Dart code does not
  read `MlsGroupState.bytes`.

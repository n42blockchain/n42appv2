# 2026-06-28 NFT Batch Transfer

## Scope

Task T13: NFT gallery multi-select and sequential batch transfer for ERC-721 /
ERC-1155.

## Implementation

- Added `NftBatchTransferUtils`:
  - allows EVM `ERC721` and `ERC1155` only;
  - rejects Solana NFTs, Ordinals, empty contracts, empty token IDs, and
    unsupported standards;
  - provides stable selection keys.
- Added `NftBatchSendPage`:
  - accepts selected NFTs from one chain;
  - validates recipient once;
  - reuses `NftSender` for each selected NFT;
  - sends one transaction per NFT in sequence;
  - shows per-item pending/sending/success/failed status;
  - retries only failed items.
- Updated `NftListPage`:
  - long press enters selection mode;
  - toolbar toggle enters selection mode;
  - cards show selected check state without changing spam hide/grouping logic;
  - selected NFTs open the batch send page.

ERC-1155 batch selection sends quantity `1` for each selected token to avoid
accidentally transferring an entire multi-balance token.

## 首个 gate：LiveKit 服务端

发现值：

```json
{
  "org.matrix.msc4143.rtc_foci": [{
    "type": "livekit",
    "livekit_service_url": "https://m.si46.world/livekit/jwt"
  }]
}
```

端点实测：

```text
GET  /livekit/jwt          -> 301 Location: /livekit/jwt/
POST /livekit/jwt/         -> 404 page not found
POST /livekit/jwt/sfu/get  -> 400 Missing room parameter
```

App 真机错误为 `livekit_token_fetch_failed (301)`。官方 MatrixRTC `/sfu/get` 存活，
但直播传 `role` 后只走 legacy URL，因此定性为服务端/role 协商不匹配。按任务红线
未修改 JWT URL、role 或回退语义。

## 发现并修复的问题

### LiveKit 失败会回滚 Matrix 房间，导致非视频功能也不可用

修复前 `GoLivePage` 把 `joinAsBroadcaster` 与 Matrix 加房放在同一失败回滚块；生产
legacy JWT 返回 301 后会退出刚创建的 Matrix 房间，任务书所述“视频失败后其余
20+ 项照常测试”实际上不成立。

`90d158f6` 将启动流程拆为两层：

1. Matrix 建房/加房失败仍回滚；
2. LiveKit 失败只清理视频服务，继续启动 Matrix 心跳并进入直播状态；
3. 页面展示“视频暂不可用，其他直播功能可继续使用”及原始错误；
4. 无视频时隐藏摄像头切换与麦克风按钮。

真机修复后创建房间并保持直播页，示例 roomId：
`!X4zPsQHgsacc6RNgBtB:m.si46.world`、`!SYOpIyczcpEemq5cE7:m.si46.world`。

## 自动化与设备限制

- iOS Profile 集成测试每次覆盖安装都会重新触发 Local Network、相机或麦克风权限；
  无线调试发生过 Flutter VM Service discovery 超时/工具崩溃。
- 有线 iPhone 的 WebDriverAgent 后续被 iOS 判定 developer certificate 未信任，
  无法继续代点系统权限；不属于 App 登录失败。
- Android APK 为 610 MB；唯一一次本轮重试由设备明确取消安装。按既有要求未反复
  尝试或清除用户数据。
- 第二台 iPhone 观众脚本在进入已过期房间前已输出 `T29_PEER wallet login: PASS`；
  因主播保活到期，未把后续失败计为产品 FAIL。

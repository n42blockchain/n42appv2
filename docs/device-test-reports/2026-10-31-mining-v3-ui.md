# Mining V3 dashboard redesign — device validation

Date: 2026-10-31, America/Toronto. Repository: `n42appv2`; delivery branch: `feat/mining-v3-ui`.

The V3 page now uses the app's shared cards, typography and semantic colors: a blue session card with start/pause, verification statistics, an honest rewards state, and a filterable recent-block list. Node configuration and individual block details open in sheets. Raw connection diagnostics are behind an expandable item in settings.

## Data boundaries

- Session time comes from the native `startedAtMs`. It freezes when this UI observes a stop. An unavailable start/end time is shown as unknown. This is session time, not lifetime mining time.
- Native counters supply verified/certified totals. Verification success uses verified and failed attempts. Average verification time uses the observed recent blocks with SDK latency, excluding failed records.
- History is bounded to 100 observed blocks per session. It combines native log events with structured latest-block metadata; it is not complete chain history. Certificate status/signers belong to each block, not the unrelated last global certificate.
- The SDK provides no reward amounts. The page shows **Not reported**, with no invented token balance, yield, or V2 reward reuse.
- Recorded block times retain the SDK's time string. They are not converted to a presumed time zone.
- New labels have English and Traditional Chinese translations. Other locales use the generated English fallback for these new labels.

## Included change and validation

An authenticated account with no UUID-scoped wallet record no longer falls back to the shared `AstranetWallet` record. Login and logout invalidate both wallet index providers along with the wallet list. This prevents another account's local wallet list and balances from being adopted on the same device; the anonymous wallet record is left intact.

The regression test `authenticated account does not inherit the default wallet list` failed against the previous provider behavior and passed after the fix. Wallet provider and aggregated-balance coverage passed: 28 tests. `flutter analyze --no-fatal-infos` exited 0 with 278 existing info-level diagnostics and no warning/error in the changed files. Account isolation still needs confirmation on a physical device with the reported account flow.

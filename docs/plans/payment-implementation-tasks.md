# 转账与红包实施任务

2026-09-20。用户授权准备代码并通过测试网/测试账号验证；外部 API 账号、商务签约及生产准入由人工办理。设计依据：[海外支付方案](payments-red-packets-overseas-2026-09-20.md)。

## 执行约定

每项由代理在独占范围实现，主代理审查资金与账户边界、验证后单独提交。只传必要上下文。真实资金、主网部署不在本轮范围。模拟、本地链、公共测试网、供应商沙盒分别标识，不互相冒充。未实际调用测试网不得报告测试网已通过。

## 人工交接

- 确认运营主体和首批国家；向法币渠道明确消费者 P2P 与红包资金流。
- 申请 Transak 与选定法币渠道沙盒，提供配置文件位置；不要在聊天或 Git 中发送密钥。
- 确认回调域名、供应商验签协议、客户授权/SCA 和资金预留能力。
- 生产准入、实名材料、签约、资金保管和合约独立审计由人工推进。

**提交**：`26172d3`

**Nonce 验证流程**：
```
前端  generateNonce() → rawNonce (32 chars)
      sha256(rawNonce) → hashedNonce → 传给 Apple SDK
Apple 将 sha256(nonce) 嵌入 identityToken JWT 的 nonce claim
前端  rawNonce 随登录请求发给后端
后端  sha256(rawNonce) === token.nonce → JWT 合法
```

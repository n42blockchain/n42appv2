# N42 Wallet 全量回归测试手册

> 适用对象：测试同事执行版本回归测试
> 适用平台：Android / iOS（macOS / Web / Windows 暂不在本轮测试范围内）
> 最近更新：2026-07-10

---

## 一、概述

本文档用于指导 N42 Wallet（企业级加密钱包 App）在发版前的全量回归测试。测试同事可按「四、功能测试用例清单」逐模块执行，每条用例包含操作步骤、预期结果与优先级，测试时可直接勾选记录结果（通过/失败/阻塞）。

建议测试节奏：
- **P0 用例**：每次发版必测（核心资产安全、转账收发、钱包创建导入）
- **P1 用例**：影响较大功能，每次发版尽量覆盖
- **P2 用例**：边缘场景/次要功能，可视测试窗口酌情抽测

---

## 二、测试环境与账号准备

### 2.1 网络选择

- 除非用例特别说明，默认在**主网**上用小额真实资产测试核心转账链路（涉及真实资金操作前与负责人确认额度）。
- 涉及新链/新功能验证时，优先使用对应链的**测试网**，测试币通过官方水龙头领取：
  - EVM 系测试网（如 Sepolia）：对应链官方 faucet
  - Solana：`solana airdrop` 或官方 faucet
  - 其他链：参考各链官方文档

### 2.2 测试钱包准备

准备至少以下几类测试钱包，覆盖不同入口：

| 类型 | 说明 |
|---|---|
| 全新创建钱包 | 走完整创建流程，含助记词备份确认 |
| 助记词导入钱包 | 使用已有测试助记词导入 |
| 私钥导入钱包 | 使用单链私钥导入 |
| Passkey/社交恢复钱包 | 用于测试 AA（账户抽象）相关功能 |
| 硬件钱包连接 | 如具备硬件设备（Ledger 等），用于硬件钱包模块测试 |
| 观察钱包（如支持） | 仅地址导入，不含私钥 |

### 2.3 测试设备矩阵

| 平台 | 建议覆盖 |
|---|---|
| Android | 1 台低端/旧系统版本机型 + 1 台主流旗舰机型，系统版本跨度尽量大（如 Android 10 与最新版本各一台） |
| iOS | 1 台旧机型（如支持的最低 iOS 版本）+ 1 台最新机型/最新 iOS |

其余维度（结合下方兼容性矩阵抽测）：
- 深色模式 / 浅色模式
- 至少 2 种非英语语言（如简体中文、日语或阿拉伯语等 RTL 语言）
- 弱网（模拟 3G/丢包）、断网重连、飞行模式切换

## 五、Bug 提交规范

### 5.1 严重程度定义

| 级别 | 定义 | 示例 |
|---|---|---|
| P0 阻断 | 核心资产安全/主流程无法使用，无绕过方案 | 转账丢失资产、创建钱包崩溃、助记词展示错误 |
| P1 严重 | 主要功能不可用或明显错误，但有可绕过方案 | Swap 报价长期失败、某条链余额显示错误 |
| P2 一般 | 局部功能缺陷，不影响核心链路 | 某语言文案错位、次要页面加载慢 |
| P3 建议 | 体验类优化建议 | 交互动效、文案措辞建议 |

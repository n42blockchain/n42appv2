### 3.1 N42 的 AA 实现 — 2026-07 逐项复核后需大幅收窄表述

此前"AA 领域深度领先/所有竞品中最完整"的定性经代码复核后**不成立**，逐项真实状态：
- **智能账户类型**: 创建页（`aa_account_create_form.dart`）实际可选 **Simple / Safe / Biconomy / Kernel** 四类（此前文档写的"含 Simple7702"与 UI 不符——7702 不在可选列表）✅ 真实
- **AA 批量交易**: `buildExecuteBatch` + 批量交易页 + DEX swap 的 approve+swap 原子批量，经真实 bundler 提交 ✅ 真实——这是 AA 侧最扎实的能力
- **EIP-7702**: ✅ **2026-07 已放行**——`simple7702_account.dart`/`eip7702_handler.dart`/部署器分支/factory 的 computeAddressForType(返回 EOA 地址)一直齐全,唯一缺口是创建页类型选择器硬编码列表不含 7702。已将 simple7702Account 加入选择器并放行 isAvailable(color/icon/描述 helper 早已覆盖该类型),用户现在可创建 EIP-7702 账户
- **Session Key**: 管理页真实可达（钱包页 → AA 首页 → Session Key 管理），可创建/撤销；**但 session key 只落本地 SQLite,从不上链安装,唯一的 AA 签名路径（`aa_transfer_handler.dart`）签名时也从不使用它**——是"只能管理、不产生任何效力"的摆设 ⚠️
- **Paymaster**: UserOp 打包管线支持 `setPaymaster`,但入口 gate 要求调用方传 `paymasterData`,**全仓所有真实调用方均不传——恒空**,`PaymasterService` 也从不真正调 `pm_getPaymasterData`。从无一笔真实 gas 代付发生 ⚠️
